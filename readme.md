# 📊 7 Days of PostgreSQL Challenge

Welcome to my **7 Days of PostgreSQL Challenge**! 🚀

This repository documents my daily SQL learning journey as I work toward becoming a **Data Analyst**. I believe that consistency is the key to mastering any skill, so I challenged myself to practice PostgreSQL every day and strengthen my understanding of databases and data analysis.

As a beginner in the Data Analytics field, I consider SQL to be the first and most important step of my journey. Through hands-on practice and real-world inspired datasets, I explored various SQL concepts ranging from basic CRUD operations to advanced joins and analytical queries.

The goal of this challenge is not only to learn SQL syntax but also to develop analytical thinking, problem-solving abilities, and database management skills that are essential for a successful career in Data Analytics.

---

## 📅 Day 1 - SQL Fundamentals & CRUD Operations

Created and managed an Employee database using SQL. Practiced creating tables, inserting records, retrieving data, updating employee details, and deleting records. Learned how to use the `WHERE` clause for conditional filtering and gained a strong understanding of basic CRUD operations.

---

## 📅 Day 2 - Data Filtering & Sorting

Worked on a Blinkit-inspired product database and explored data filtering techniques. Practiced `WHERE`, `LIKE`, `BETWEEN`, `DISTINCT`, and `ORDER BY` clauses to search, sort, and organize data. Also learned how to handle NULL values and perform conditional updates.

---

## 📅 Day 3 - Aggregation & Reporting

Analyzed a Computer Science Books database using aggregate functions. Practiced `COUNT()`, `SUM()`, `AVG()`, `MAX()`, and `MIN()` along with `GROUP BY` and `HAVING` clauses. Generated subject-wise reports and learned how SQL is used for business reporting and analytics.

---

## 📅 Day 4 - Transaction Management

Explored Transaction Control Language (TCL) concepts using banking and student databases. Practiced `COMMIT`, `ROLLBACK`, `SAVEPOINT`, and `RELEASE SAVEPOINT` commands. Learned how databases maintain data consistency and prevent accidental data loss.

---

## 📅 Day 5 - SQL Functions & Data Transformation

Worked with banking account records to understand SQL functions. Practiced string functions, date functions, and aggregate functions for data transformation and analysis. Learned how SQL can be used to clean, format, and process data efficiently.

---

## 📅 Day 6 - Subqueries & Nested Queries

Solved analytical SQL problems using subqueries and nested queries. Practiced finding top performers, comparing records, calculating second-highest values, and using `ANY` and `ALL` operators. Improved problem-solving skills and learned advanced data filtering techniques.

---

## 📅 Day 7 - Joins & Multi-Table Analysis

Worked with multiple related tables to understand relational database concepts. Practiced `INNER JOIN`, `LEFT JOIN`, `SELF JOIN`, and multi-table queries. Combined data from different tables and generated analytical reports similar to real-world business scenarios.
